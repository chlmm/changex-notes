# 王国血脉

> 作者: 8号女巫
> 分类: 小说/奇幻/权谋

## 作品概述

《王国血脉》（又名《无主之剑》）是一部融合了异界穿越、宫廷权谋、硬核奇幻与深度心理博弈的高口碑网络小说。地球社会科学研究生吴葺仁穿越到奇幻世界埃罗尔，成为星辰王国失散多年的唯一皇位继承人——泰尔斯·璨星，并在动荡的帝国余晖中挣扎求生、寻回自我并试图重塑世界秩序。 → [[基础/overview|更多]]

### 故事主线

泰尔斯从永星城下城区的乞儿起步，在黑街兄弟会的残暴统治下求生，杀掉头目奎德后策划大逃亡，在红坊街混乱中接触魔能师艾希达，被王室卫队寻回。确认王室血脉后接受贵族教育，卷入宫廷权力博弈，经历血族绑架并与女大公瑟琳娜达成"星夜同盟"。随后出使北地埃克斯特，在龙霄城多方势力夹缝中求存，推举塞尔玛为女大公。六年后前往翡翠城处理继承权争端，直面权力的"罗网"，以"国王的对手"身份独立决策。 → [[解读/storyline|十大篇章详解]]

### 人物分析

- **泰尔斯·璨星（吴葺仁）**：主角，前世为地球社会科学研究生，拒绝成为棋子，坚持"选择定义自我"
- **凯瑟尔五世**：星辰王国国王，"铁拳王"，绝对理性的统治者
- **塞尔玛（小滑头）**：北地女大公，与泰尔斯跨越身份的友谊
- **查曼·伦巴**：黑沙大公，智商在线的反派，有坚定立场与长远布局
- **瑟琳娜**：血族女大公，与泰尔斯达成星夜同盟
- **詹恩·凯文迪尔**：南岸领主，展示统治的复杂链条

### 主题思想

1. **选择与自我**："魔能次约：谨守自我"——真正属于自己的锚点，是面对困境时自主做出的每一个选择
2. **血脉与命运**：拒绝被血脉定义，追问自己是棋子还是能独立选择的个人
3. **权力的罗网**：统治者和被统治者都深陷其中，上位者的举动在底层激起不可估量的连锁反应
4. **统治的界限**：统治的根基不在于血统，而在于"习惯"和"契约"
5. **凡人智慧对抗超凡力量**：以弱博强的生存艺术

### 写作风格

- 节奏严密、逻辑性极强，不追求"打怪升级"
- 社会科学思维贯穿始终，用现代学术方法解构古代权谋
- 冷峻写实基调，极高密度的政治博弈与心理战描写
- 硬核权谋中穿插动人的情感瞬间
