# 作品概述

《王国血脉》（又名《无主之剑》）是一部融合了**异界穿越、宫廷权谋、硬核奇幻**与**深度心理博弈**的高口碑网络小说。

地球社会科学研究生**吴葺仁**穿越到奇幻世界埃罗尔，成为星辰王国失散多年的唯一皇位继承人——**泰尔斯·璨星**，并在动荡的帝国余晖中挣扎求生、寻回自我并试图重塑世界秩序。

## 核心特点

1. **独特的"社会科学"视角**：主角常利用前世的社科知识（密尔归纳法、政治经济学、发展心理学等）来分析异世界局势和自身异能，逻辑缜密、带有理性思辨色彩
2. **宏大且冷峻的世界观**：世界名为"埃罗尔"，拥有严谨的力量体系——终结之力（人类战士的超凡力量）、魔能与魔能师（灾祸之源的禁忌力量）、反魔武装（封印魔能师的传奇武器），充满黑暗与真实感 → [[worldbuilding|世界观详解]]
3. **极高密度的政治权谋**：每一个举动背后都隐藏着多方势力的博弈，反派智商在线，每个人都有坚定的立场与长远布局
4. **深刻的主题**：血脉与选择——在腐朽的王国体制中，通过一次次痛苦而坚定的抉择，对抗不可避免的命运
5. **沉重而感人的情感羁绊**：基调冷峻但不乏动人瞬间，友谊与同生共死的经历为硬核作品增添温情

## 写作风格

- 节奏严密、逻辑性极强，不追求简单的"打怪升级"
- 社会科学思维贯穿始终，用现代学术方法解构古代权谋
- 冷峻写实的基调，世界充满黑暗与真实感
- 极高密度的政治博弈与心理战描写
- 在硬核权谋中穿插动人的情感瞬间
- 致力于展现真实、复杂且动荡的时代图景
