# 中国是部金融史

> 分类: 非虚构/历史/金融

## 书籍概述

本书从中国三千年历史角度审视金融发展，批判当代金融学过度依赖西方数学模型，主张金融应回归人本与历史属性，发掘古中国金融智慧。

### 核心观点

1. **金融的本质是诚信与道德**
   - 金融不应是冷冰冰的数学模型
   - "诚信"是金融的终极天道
   - 核心论证: 西周盛世与王朝覆灭的对比，现代金融危机的根源

2. **义利并重的财富精神**
   - 获取财富的途径必须道德（借用孔子思想）
   - "义利并重"是经济秩序的根基
   - 失去道德的社会会变成"丛林社会"

3. **"藏富于民"是国家强盛的关键**
   - 治国之道在于富民
   - 强国与弱国的区别：强国的钱在百姓手里，弱国的钱在国王的钱箱里
   - 引用管仲语录："王者藏于民，霸者藏于大夫"

4. **权力与财富的博弈**
   - 王朝覆灭往往因封建官僚形成强势分利集团
   - 利用权力掠夺财富，导致小农失去土地成为流民
   - "皇权—封建官僚—小农"的社会框架分析

5. **规律不可违背,尊重经济客观条件**
   - 实例: 汉武帝、王莽、董卓的货币政策失败
   - 思想: 即使强大君主也无法通过强制货币政策对抗经济规律

6. **权力不能发号施令于经济**
   - 实例: 赢胡亥的案例
   - 思想: "兵戈可以消灭生命，但无法消灭生生不息的货币"

7. **向富人征税的现实困境**
   - 富人与官僚合一，难以推行"按财计税"
   - 税收最终被转嫁到自耕农和佃农身上

### 观点评价与反思

**积极意义**：
- 从中国历史角度审视金融，视角独特
- 批判过度数学化的金融学，强调人文与历史维度
- "藏富于民"等观点对当代有重要启示
- 将复杂金融理论用历史案例解释，通俗易懂

**值得商榷之处**：
- 对西方金融理论的批判可能过于绝对
- 历史案例的解读可能存在选择性偏差
- 部分观点（如道德至上）在现代复杂金融体系中操作性不强
- 古今对比时需要考虑时代背景的差异

**核心思想总结**：
> 金融不仅仅是金钱和模型，它关乎人性、道德与权力的博弈。一个健康的金融体系必须建立在诚信的基础上，并始终坚持藏富于民。
> 
> 权力是修剪枝叶的剪刀，而民间的财富与诚信则是深埋地下的根基；若剪刀为了装饰自己而剪断了根基，整棵大树必然会枯萎。
