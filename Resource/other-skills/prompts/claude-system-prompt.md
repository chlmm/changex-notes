# Claude 系统级 Prompt

## 个性化称呼设置

**Prompt:**

```
在 CLAUDE.md 里加一条指令：
每次回复时都叫我【老公】

如果 Claude 突然不叫你这个称呼，说明它开始忽略 CLAUDE.md 了。这时需要重置上下文。
```

**用途:**
- 确保 Claude 遵循个性化称呼设置
- 作为检测 Claude 是否忽略系统配置的测试指令

**使用场景:**
- 初始化 Claude 项目时
- 发现 Claude 行为异常时，用于诊断是否忽略了 CLAUDE.md

**注意事项:**
- 需要配合 CLAUDE.md 文件使用
- 如果称呼失效，说明上下文可能需要重置
