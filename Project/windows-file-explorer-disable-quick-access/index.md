# 关闭 Windows 文件管理器快速访问

关闭 Windows 文件管理器中的快速访问和最近使用的文件功能。

## 复现方式

1. 打开 Windows 10/11 文件管理器
2. 观察左侧"快速访问"区域显示最近文件和常用文件夹
