# 资源收藏管理器

## 功能概述

快速收藏发现的各类资源，按类型分类暂存到 `待收藏.md`，后续按需整理到项目对应目录。

## 支持的资源类型

| 类型 | 说明 | 整理目标 |
|------|------|---------|
| **Prompt** | AI 提示词 | `prompts/` |
| **MCP工具** | Model Context Protocol 工具 | `skills/mcp-skills/` |
| **软件** | GUI 软件、浏览器扩展 | `user-skills/software/` |
| **学习资源** | 文章、教程、视频、书籍 | `资源学习/` |
| **金句/观点** | 有价值的观点、类比、洞察 | `insights/` 或 `quotes/` |
| **项目** | 开源项目、代码库 | `资源学习/项目/` |
| **其他** | 无法归类的资源 | `待收藏.md` 单独区域 |

## 工作流程

### 1. 接收资源信息

用户提供：
- **资源名称**（必需）
- **资源类型**（必需）
- **链接/内容**（可选）
- **备注/标签**（可选）

### 2. 分类存储

根据资源类型，添加到 `待收藏.md` 对应区域：

```markdown
## 待整理的 Prompts

- [ ] [名称] | [链接] | [备注]

## 待整理的 MCP工具

- [ ] [名称] | [链接] | [备注]

## 待整理的 软件/工具

- [ ] [名称] | [链接] | [备注]

## 待整理的 学习资源

- [ ] [名称] | [类型:文章/视频/书籍] | [链接] | [备注]

## 待整理的 金句/观点

- [ ] [内容摘要] | [来源] | [标签]

## 待整理的 其他资源

- [ ] [名称] | [类型] | [链接] | [备注]
```

### 3. 后续整理

定期（如每周）将分类好的资源整理到目标目录：

| 类型 | 整理动作 |
|------|---------|
| Prompt | 创建 `prompts/{name}.md` |
| MCP工具 | 创建 `skills/mcp-skills/{name}/SKILL.md` |
| 软件 | 创建 `user-skills/software/{name}/USER-SKILL.md` |
| 学习资源 | 使用对应 skill 创建到 `资源学习/` |
| 金句/观点 | 创建 `insights/{category}.md` 或汇总文件 |

## 使用示例

### 示例 1：收藏 Prompt

**用户输入：**
```
帮我收藏这个 Prompt：
名称：Claude 称呼设置
内容：在 CLAUDE.md 里加一条指令，每次回复都叫我【老公】
类型：Prompt
```

**执行结果：**
添加到 `待收藏.md` 的 "## 待整理的 Prompts" 区域：
```markdown
## 待整理的 Prompts

- [ ] Claude 称呼设置 | - | 系统级配置，检测是否忽略 CLAUDE.md
```

### 示例 2：收藏 MCP 工具

**用户输入：**
```
收藏这个 MCP 工具：
名称：Jina AI MCP Server
链接：https://github.com/jina-ai/MCP
说明：AI 搜索相关的 MCP 工具
```

**执行结果：**
添加到 `待收藏.md` 的 "## 待整理的 MCP工具" 区域

### 示例 3：收藏金句/观点

**用户输入：**
```
收藏这个观点：
创业是新时代的科举，成功可以改变命运和阶层
投资是新时代的察举，好的苗子主要靠推荐
```

**执行结果：**
添加到 `待收藏.md` 的 "## 待整理的 金句/观点" 区域：
```markdown
## 待整理的 金句/观点

- [ ] 创业与投资的类比 | - | 创业/科举，投资/察举，社会阶层
```

### 示例 4：批量整理

**用户输入：**
```
帮我整理所有 Prompt 类型的资源到 prompts/ 目录
```

**执行步骤：**
1. 读取 `待收藏.md` 中 "## 待整理的 Prompts" 区域
2. 为每个 Prompt 创建 `prompts/{name}.md` 文件
3. 更新已整理记录
4. 从待整理列表中移除已整理的条目

## 注意事项

1. **严格分类** - 不同类型的资源必须放到对应区域，不要混放
2. **快速收藏** - 先收藏进来，不要过度整理
3. **定期清理** - 建议每周整理一次，避免堆积
4. **标记状态** - 使用 `[ ]` 待整理、`[~]` 整理中、`[x]` 已整理
5. **保留来源** - 记录链接或来源，便于后续查找
