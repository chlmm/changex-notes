# 自定义与扩展

## 键盘快捷键自定义

### 修改快捷键

```
1. 工具 → 选项 → 环境 → 键盘
2. 搜索命令名或操作名
3. 在"按快捷键"栏按下你要设置的组合键
4. 点击"分配"
5. 确认
```

### 常见自定义建议

| 操作 | 默认键 | 建议改为 | 原因 |
|------|--------|---------|------|
| 跳转定义 | F12 | 保留 | 通用约定 |
| 切换h/cpp | Ctrl+K, Ctrl+O | Ctrl+Tab 或 Alt+O | 更顺手，减少组合键次数 |

### 快捷键方案

VS 支持多种预设方案：

| 方案 | 适合 | 设置位置 |
|------|------|---------|
| Default | VS 原生 | 选项 → 键盘 → 映射方案 |
| Visual Studio Code | VS Code 用户 | 同上 |
| ReSharper (C++) | 装了 R++ 的用户 | 同上 |

**建议**：如果你同时用 VS Code，选 "Visual Studio Code" 方案可以减少记忆负担。

## 主题与外观

### 切换主题

```
工具 → 选项 → 环境 → 常规 → 颜色主题
├── Blue（经典蓝色）
├── Dark（深色，推荐长时间编码）
├── Light（浅色）
└── Blue (Extra Contrast)（高对比蓝色）
```

### 字体设置

```
工具 → 选项 → 环境 → 字体和颜色
├── 字体：Cascadia Code / Consolas / JetBrains Mono
├── 大小：12-14px 常见
└── 可单独设置各语法元素的颜色
```

**推荐字体**：

| 字体 | 特点 | 来源 |
|------|------|------|
| Cascadia Code | VS 默认，支持连字 | 内置 |
| Consolas | 经典等宽字体 | Windows 内置 |
| JetBrains Mono | 优秀可读性，支持连字 | 免费下载 |
| Fira Code | 热门编程字体，连字丰富 | 免费下载 |

### 启用连字 (Ligatures)

```
1. 安装支持连字的字体（如 Cascadia Code）
2. 选项 → 环境 → 字体和颜色 → 字体 → 选择支持连字的字体
3. 选项 → 文本编辑器 → 高级 → 启用连字 → 是
```

## 编辑器配置

### 显示设置

```
工具 → 选项 → 文本编辑器 → C/C++ → 常规
├── 行号 → 开启（强烈推荐）
├── 启用点击 URL → 按需
└── 选定内容的边距 → 开启（方便选中代码块）
```

### 代码格式化设置

```
工具 → 选项 → 文本编辑器 → C/C++ → 格式设置
├── 常规 → 键入时自动设置格式 → 按习惯开关
├── 缩进 → 智能缩进（推荐）
├── 大括号位置 → 按团队规范选择
└── 空格/制表符 → 按团队规范选择
```

### IntelliSense 设置

```
工具 → 选项 → 文本编辑器 → C/C++ → 高级
├── 自动列出成员 → 开启
├── 参数信息 → 开启
├── 禁用 IntelliSense → 关闭（除非用 Clangd 替代）
└── 最大缓存百分比 → 默认 50%，大项目可增大
```

## 导出/导入设置

### 导出你的配置

```
1. 工具 → 导入和导出设置
2. 选择"导出选定的环境设置"
3. 勾选要导出的项（快捷键、字体颜色、选项等）
4. 保存为 .vssettings 文件
```

### 导入配置

```
1. 工具 → 导入和导出设置
2. 选择"导入选定的环境设置"
3. 选择 .vssettings 文件
4. 选择要导入的项
```

**用途**：换电脑或重装 VS 时快速恢复你的配置。

## 常见问题

### 问题：扩展安装后不生效

**解决**：
- 重启 VS
- 检查扩展是否启用：扩展 → 管理扩展 → 已安装 → 确认已启用
- 某些扩展需要特定 VS 版本或工作负载

### 问题：VS 启动太慢

**优化方向**：
- 禁用不用的扩展：扩展 → 管理扩展 → 禁用
- 关闭不常用的工具窗口
- 禁用源代码管理插件（如果不用 Git）
- 清理最近打开的项目列表
