# 代码编辑与导航

## 核心策略：理解代码的两种模式

```
你面对一段代码时...
├─ 我想理解它 ──→ 导航类操作（跳转、查看引用、调用层次）
└─ 我想修改它 ──→ 编辑类操作（重构、格式化、快速操作）
```

## 导航工作流

### 理解一个不熟悉的函数

```
1. 速览定义 → 在原地预览函数实现，不打断当前上下文
2. 如果需要完整上下文 → 跳转定义
3. 想知道谁在调用它 → 查找引用 或 调用层次
4. 看完了 → 后退 返回原位置
```

### 在头文件和源文件间工作

```
1. 在 .h 中写声明
2. 切换h/cpp → 跳到 .cpp
3. 写实现
4. 切换h/cpp → 跳回 .h
```

### 在大型项目中定位文件

```
知道文件名？  → 转到文件
知道符号名？  → 转到符号
知道行号？    → 转到行
都不确定？    → 全局搜索 关键词
```

### 理解调用关系

```
1. 光标放在函数上
2. 调用层次 → 展开调用树
3. 看到：
   ├── "Calls To" — 这个函数调用了谁
   └── "Calls From" — 谁调用了这个函数
```

## 编辑工作流

### 日常编辑节奏

```
1. 写代码
2. 格式化文档 / 格式化选区 → 保持代码风格
3. 编译当前文件 → 快速检查语法错误
4. 有灯泡提示？ → 快速操作 → 选择修复建议
```

### 注释控制

```
临时屏蔽代码 → 注释
恢复代码     → 取消注释
需要留标记？ → 用 TODO 注释 + 书签切换 标记位置
```

### 代码区域管理

```
当前文件太长？
├─ 全部折叠 → 先看整体结构
├─ 展开感兴趣的区域 → 展开折叠
└─ 反复跳转的位置 → 书签切换 标记
```

## 策略树：我找不到 X

```
找不到某个定义
├─ 知道大概名字？
│  ├─ 转到符号 → 按名称搜索
│  └─ 全局搜索 → 搜关键词
├─ 看到引用但想看实现？
│  └─ 跳转定义 / 跳转声明
├─ 不确定在哪个文件？
│  └─ 类视图 → 按命名空间/类浏览
└─ 在第三方库里？
   └─ 确认包含目录已配置，IntelliSense 才能索引到
```

## IntelliSense 相关

### IntelliSense 不工作时的排查

```
IntelliSense 卡住/报错
├─ 重建索引
│  → 项目 → Rescan Solution
├─ 清理 IntelliSense 数据库
│  → 关闭 VS → 删除 .vs 目录下的 .suo 文件
├─ 检查包含目录
│  → 属性页 → C/C++ → 附加包含目录 是否完整
└─ 检查预处理器宏
   → 条件编译可能让 IntelliSense 走错分支
```

### IntelliSense vs Clangd

| 特性 | IntelliSense | Clangd（VS 扩展） |
|------|-------------|-------------------|
| 默认启用 | 是 | 需安装扩展 |
| CMake 支持 | 需配置 | 自动读取 CMakeLists |
| 准确性 | 偶尔误报 | 通常更准确 |
| 性能 | 大项目可能卡 | 通常更流畅 |
| 重构能力 | 内置 | 内置 |

如果 IntelliSense 经常出问题，可以安装 Clangd 扩展替代。

## 类视图使用场景

类视图（Class View）在以下情况比解决方案资源管理器更好用：

- 按命名空间/类层级浏览，而不是按文件目录
- 快速找到一个类的所有成员
- 查看继承关系
- 项目文件很多但想定位到某个类

## 常见问题

### 问题：跳转定义跳到了错误的位置

**原因**：多个文件有同名符号，IntelliSense 猜错了。

**解决**：查找引用 → 手动确认哪个是你要的。

### 问题：查找引用遗漏了某些引用

**原因**：IntelliSense 索引不完整，或引用在条件编译块内。

**解决**：全局搜索 做补充验证。
