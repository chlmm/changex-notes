# Visual Studio 快捷键速查

> 按意图分类。工作流文件中只写操作名，需要查键时搜本文件。
> 操作名是规范化约定，workflow 文件和本文件必须使用相同的操作名。

## 我想跳转...

| 操作名 | 快捷键 | 说明 |
|--------|--------|------|
| 跳转定义 | F12 | 跳到符号的定义处 |
| 跳转声明 | Ctrl+F12 | 跳到符号的声明处 |
| 速览定义 | Alt+F12 | 在原地弹出定义预览窗口，不离开当前位置 |
| 查找引用 | Shift+F12 | 列出所有引用该符号的位置 |
| 切换h/cpp | Ctrl+K, Ctrl+O | 在头文件和源文件间切换 |
| 调用层次 | Ctrl+K, Ctrl+T | 查看函数的调用者和被调用者 |
| 转到行 | Ctrl+G | 跳转到指定行号 |
| 转到文件 | Ctrl+Shift+T | 按文件名搜索并跳转 |
| 转到符号 | Ctrl+Shift+Period | 按符号名搜索并跳转 |
| 转到成员 | Ctrl+Shift+F12 | 在当前文件中跳转到下一个引用/成员 |
| 后退 | Ctrl+- | 导航回上一个位置 |
| 前进 | Ctrl+Shift+- | 导航到下一个位置 |

## 我想搜索...

| 操作名 | 快捷键 | 说明 |
|--------|--------|------|
| 全局搜索 | Ctrl+Shift+F | 在整个解决方案中搜索文本 |
| 快速搜索 | Ctrl+F | 在当前文件中搜索 |
| 替换 | Ctrl+H | 当前文件中查找替换 |
| 全局替换 | Ctrl+Shift+H | 整个解决方案中查找替换 |
| 增量搜索 | Ctrl+I | 输入即搜索，不弹出对话框 |
| 搜索命令 | Ctrl+Q | 搜索菜单命令和选项 |
