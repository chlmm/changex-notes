# 代码编辑与导航

## 核心概念：Locator

Qt Creator 的 Locator（Ctrl+K）是整个导航系统的核心，相当于 VS 的命令面板 + 文件跳转 + 符号搜索三合一。

```
你需要找什么？
├── 文件？  → Locator 直接输入文件名
├── 类/函数？ → Locator 输入 :符号名
├── 当前文件符号？ → Locator 输入 .符号名
├── 帮助文档？ → Locator 输入 ?类名
├── 命令？  → Locator 输入 !命令名
└── 行号？  → Locator 输入 l行号
```

详见 [shortcuts.md](../shortcuts.md) 的 Locator 命令速查。

## 导航工作流

### 理解一个不熟悉的函数

```
1. 光标放在函数名上 → 跳转定义 → 看实现
2. 切换h/cpp → 跳到头文件看声明
3. 查找引用 → 看谁在调用
4. 看完了 → 后退 返回原位置
```

### 在头文件和源文件间工作

```
1. 在 .h 中写声明
2. 切换h/cpp → 跳到 .cpp
3. 写实现
4. 切换h/cpp → 跳回 .h
```

**Qt Creator 的 F4 比 VS 的 Ctrl+K,Ctrl+O 更方便**——一个键搞定。

### 在大型项目中定位文件

```
知道文件名？  → Locator 直接输入
知道符号名？  → Locator 输入 :符号名
都不确定？    → 全局搜索 关键词
想浏览项目结构？ → 项目面板（左侧边栏）
```

### 利用大纲视图快速定位

大纲（Outline）显示当前文件的类、函数、变量列表，在大型文件中快速跳转。

```
1. 打开大纲 → 侧边栏 Outline 面板
2. 在列表中点击目标符号
3. 编辑器跳转到对应位置
```

## 编辑工作流

### 日常编辑节奏

```
1. 写代码（自动补全 会自动弹出）
2. 格式化文档 → 保持代码风格
3. 有错误？ → 问题面板 查看错误列表
4. 有快速修复建议？ → 快速修复 → 选择修复
```

### 分屏工作

Qt Creator 的分屏对 C++ 开发特别有用——同时看 .h 和 .cpp：

```
1. 分屏（左右） → 编辑区分成两半
2. 一边打开 .h，另一边打开 .cpp
3. 不需要了？ → 取消分屏
```

### 使用 FakeVim（可选）

Qt Creator 内置 Vim 模拟：

```
1. 工具 → 选项 → FakeVim → 启用
2. 编辑器进入 Vim 模式
3. 可以用 Vim 键位操作
```

**建议**：如果你是 Vim 用户，开启后效率提升明显；如果不是，忽略此功能。

## 代码补全

### 补全触发方式

| 方式 | 触发 |
|------|------|
| 自动弹出 | 输入 `.`、`->`、`::` 后自动触发 |
| 手动触发 | 自动补全 |

### 补全中的图标含义

| 图标 | 含义 |
|------|------|
| 🔵 蓝色圆形 | 类 |
| 🟢 绿色圆形 | 枚举 |
| 🟡 黄色钥匙 | 函数/方法 |
| 🔴 红色方块 | 变量/成员 |
| 🟣 紫色菱形 | 宏定义 |
| ⚡ 闪电 | 信号 |
| 🔌 插头 | 槽函数 |

## 策略树：我找不到 X

```
找不到某个定义
├── 知道大概名字？
│   ├── Locator 输入 :名字
│   └── 全局搜索 搜关键词
├── 看到引用但想看实现？
│   └── 跳转定义 / 跳转声明
├── 不确定在哪个文件？
│   └── 项目面板 浏览目录结构
├── 想看当前文件有哪些符号？
│   └── 大纲面板
└── 在 Qt 类库里？
    └── Locator 输入 ?类名 打开帮助文档
```

## Qt 特有导航

### 跳转到信号/槽的实现

```
1. 光标放在信号或槽的声明上
2. 跳转定义 → 跳到 emit/connect 的地方
3. 或右键 → Refactor → Find Signals/Slots
```

### 查看 Qt 帮助文档

Qt Creator 内置了完整的 Qt 文档：

```
1. 光标放在 Qt 类/函数上
2. 按 F1 → 右侧打开帮助面板
3. 或 Locator 输入 ?QWidget → 直接搜索
```

## 常见问题

### 问题：代码补全不工作

```
排查步骤
├── 项目是否成功配置？→ 检查问题面板 是否有 CMake/qmake 错误
├── Clangd 是否启用？→ 工具 → 选项 → C++ → Clangd → 检查设置
├── 项目太大索引慢？→ 等待索引完成（右下角进度条）
└── 仍然不行？→ 构建 → 清除 → 重新构建，重启 Qt Creator
```

### 问题：跳转定义跳到了错误的位置

**原因**：同名符号在多个文件中存在。

**解决**：查找引用 → 手动确认哪个是你要的。
