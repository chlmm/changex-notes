# 社交邀请

## 关键句型

### 发出邀请

| 正式度 | 表达 |
|--------|------|
| 随意 | "How about a drink tonight?" / "Wanna grab lunch?" / "Want to come over this weekend?" |
| 中性 | "Would you like to join us for dinner on Friday?" / "We're having a small get-together — would you be able to make it?" |
| 正式 | "I'd like to invite you to..." / "We'd be delighted if you could join us for..." |

### 说明细节

| 情况 | 表达 |
|------|------|
| 时间 | "Around 7ish?" / "Let's say 7 PM." / "Any time after 6 works for me." |
| 地点 | "There's a great place on Main Street." / "I'll send you the address." / "At my place." |
| 集合方式 | "Shall I pick you up?" / "Let's meet there at 7." / "I'll send you a pin." |

### 接受邀请

| 正式度 | 表达 |
|--------|------|
| 随意 | "Sounds great!" / "Count me in!" / "I'm down!" / "For sure!" |
| 中性 | "I'd love to, thanks!" / "That sounds like fun." / "I'd really like that." |
| 确认细节 | "What time should I be there?" / "Should I bring anything?" / "Can I bring a friend?" |

### 礼貌拒绝

| 正式度 | 表达 |
|--------|------|
| 随意 | "Ah, I can't this time." / "Maybe next time!" / "Rain check?" |
| 中性 | "I'd love to, but I have something that evening." / "I wish I could, but I'm booked up this week." |
| 正式 | "Thank you so much for the invitation. Unfortunately, I won't be able to make it." |
| 给替代方案 | "I can't on Friday, but how about Saturday?" / "Next week works better for me." |

### 请客与分摊

| 情况 | 表达 |
|------|------|
| 你请客 | "My treat!" / "It's on me." / "I've got this one." / "This one's on me — you can get the next one." |
| AA制 | "Let's split it." / "Shall we go Dutch?" / "Let's just split the bill." |
| 对方说"我请"时 | "Are you sure? Thank you!" / "Well, next time it's on me." |

### 席间/聚会中

| 情况 | 表达 |
|------|------|
| 敬酒 | "Cheers!" / "Bottoms up!" / "Here's to [occasion]!" |
| 劝吃劝喝 | "Help yourself!" / "Have some more." / "There's plenty more." |
| 感谢款待 | "Thanks for having me over." / "This was really lovely." / "I had a great time." |
| 提前离开 | "I should probably get going." / "It's getting late — I should head out." / "Early day tomorrow, so I'd better take off." |

### 收到邀请后跟进

| 情况 | 表达 |
|------|------|
| 确认出席 | "Just confirming — I'll be there at 7!" / "Still on for Friday?" |
| 提前告知迟到 | "I might be a few minutes late." / "Running a bit behind — see you around 7:30." |
| 事后感谢 | "Thanks again for last night. Had a great time!" / "That was so much fun. We should do it again sometime." |

## 对话范例

### 范例1：随意约饭

> **你**: Hey, how about a drink tonight? There's a new place on 5th Street.
>
> **朋友**: Sounds great! What time?
>
> **你**: Around 7ish?
>
> **朋友**: Perfect. Should I bring anything?
>
> **你**: Nope, just yourself! I'll send you the address.
>
> **朋友**: Awesome, see you there.

### 范例2：礼貌拒绝 + 给替代方案

> **同事**: A few of us are getting dinner on Friday. Would you like to join?
>
> **你**: I'd love to, but I have plans this Friday. Could we do next week instead?
>
> **同事**: Sure! How about Tuesday?
>
> **你**: Tuesday works. Thanks for thinking of me!

### 范例3：聚会上提前离开

> **你**: Hey, I should probably get going. Early day tomorrow.
>
> **主人**: Already? Stay for one more drink!
>
> **你**: I really should head out, but thanks so much for having me. I had a great time.
>
> **主人**: Glad you could make it! Let's do this again soon.
>
> **你**: Definitely. I'll reach out next week. Goodnight!

## 文化提示

- **"Rain check"** — 意思是"这次不行，下次补上"，非常常见的礼貌拒绝方式。源自棒球因雨取消比赛后补赛的传统。
- **"Count me in"** 比 "I will go" 更自然口语。
- **"Should I bring anything?"** 是赴约时的标准礼貌问题。通常主人会说 "Just yourself" 或 "Maybe a bottle of wine if you like."
- **请客文化差异** — 在中国抢着买单是常态，但在英语文化中，"Going Dutch"（AA制）非常普遍，不会被认为小气。
- **迟到 5-10 分钟可以接受** — 但要提前发消息说一声。超过 15 分钟就不太好了。
- **离开时不一定要等到最后** — 在欧美聚会中，提前离开是正常的，只要跟主人打个招呼就行，不需要逐个告别。
- **"Bottoms up!"** 是干杯的意思，通常用于朋友间的酒局，正式场合用 "Cheers" 就够了。

## 常见错误

| ❌ 不要这样说 | ✅ 应该说 | 原因 |
|-------------|-----------|------|
| "I don't want to go" | "I can't make it this time" / "Maybe next time" | 直接说不想去很伤人 |
| "Why didn't you invite me?" | "I heard you guys had dinner — sounds like fun! Hope to join next time." | 质问对方不邀请你会让气氛尴尬 |
| "You must come" | "I'd love it if you could make it" / "Hope you can join us" | "Must" 给人压力 |
| 在聚会上一声不吭就走了 | 跟主人说一声再走 | 不辞而别被认为很不礼貌 |
| 拒绝后不提供替代方案 | 加一句 "But how about next week?" | 没有替代方案的拒绝会显得不感兴趣 |
