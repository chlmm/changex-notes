# Omni 使用指南

## 概述

Omni 是一个 Chrome/Edge 浏览器扩展，提供类似 VSCode Command Palette 的全能命令面板，让你通过键盘快速执行各种浏览器操作。

## 功能特性

- 快速切换标签页
- 搜索书签和历史记录
- 执行浏览器操作
- 自定义快捷键
- 插件扩展支持

## 安装

### Chrome 商店安装

**操作步骤**:
1. 访问 Chrome 网上应用店
2. 搜索 "Omni"
3. 点击安装

### 手动安装

**操作步骤**:
1. 访问 https://github.com/alyssaxuu/omni
2. 下载并解压
3. 在 Chrome 扩展页面加载已解压的扩展

## 基础使用

### 打开命令面板

**操作步骤**:
- 按 `Ctrl/Cmd + Shift + K` 打开 Omni 面板
- 或点击浏览器工具栏图标

### 常用命令

| 命令 | 功能 |
|------|------|
| `/tabs` | 搜索标签页 |
| `/bookmarks` | 搜索书签 |
| `/history` | 搜索历史记录 |
| `/actions` | 执行操作 |
