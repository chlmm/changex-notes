# Keyviz 使用指南

## 概述

Keyviz 是一个实时按键可视化工具，当你在屏幕上按键时，会以美观的方式显示按键内容，非常适合录屏、直播和教学演示。

## 功能特性

- 实时显示按键操作
- 美观的视觉样式
- 可自定义外观和位置
- 支持鼠标点击显示
- 低资源占用
