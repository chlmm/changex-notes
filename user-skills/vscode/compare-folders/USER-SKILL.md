# VSCode Compare Folders 插件

## 概述

Compare Folders 是 VSCode 插件，可对比两个文件夹的结构和文件内容差异，并排显示 diff 视图。

## 功能特性

- 比较两个文件夹的内容差异
- 显示有差异的文件列表
- 并排显示文件 diff
- 支持文件同步操作

## 安装

### 方式一：通过 VSCode 市场安装

1. 打开 VSCode
2. 按 `Ctrl+Shift+X` (Windows/Linux) 或 `Cmd+Shift+X` (macOS) 打开扩展面板
3. 搜索 "Compare Folders"
4. 找到作者为 moshfeu 的插件，点击安装

### 方式二：通过链接安装

访问插件市场页面安装：[Compare Folders - VSCode Marketplace](https://marketplace.visualstudio.com/items?itemName=moshfeu.compare-folders)

## 使用方法

### 比较两个文件夹

**操作步骤**:
1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 "Compare Folders: Compare folders"
3. 选择要比较的第一个文件夹
4. 选择要比较的第二个文件夹
5. 在侧边栏查看差异结果

### 查看文件差异

**操作步骤**:
1. 在差异列表中点击文件
2. VSCode 会打开 diff 视图，并排显示两个版本的差异
